# 數學怪獸大亂鬥 (Math Monster Brawl)

React + Vite 教育對戰遊戲專案。  
目前已整合單人、計時、Co-op、PvP、每日挑戰、連勝塔、圖鑑、收藏/道具、家長儀表板與雙語系（`zh-TW` / `en-US`）。

## 開發指令

- `npm run dev` : 啟動開發伺服器
- `npm run build` : 產生 production build
- `npm run lint` : ESLint
- `npm run typecheck` : TypeScript 型別檢查（`tsc --noEmit`）
- `npm test` : Node 測試（`node --test`）
- `npm run test:coverage` : 輸出 coverage 報告
- `npm run test:coverage:gate` : coverage 門檻檢查（lines 80% / branches 60% / functions 70%）

## 作畫動畫試玩

- 正式戰鬥已啟用 **蒼鋼狼王最終型態、單翼狂龍** 的八格新版素材，涵蓋單人、Co-op 主副將與 PvP 雙方；其餘 49 個外觀維持原畫，未宣稱全角色作畫已完成。
- 素材按登場需要載入，載入／解碼失敗時保留原畫。所有姿勢使用固定比例與安全範圍，不因受擊換格重新計算站位；播放使用 CSS，不增加每幀 React 更新。
- 開發伺服器啟動後開啟 `/?visual=pilot`，可比較蒼鋼狼王與單翼狂龍的新作畫動畫／原素材，預覽出招，或答題進行簡化回合。
- 試玩頁支援暫停、慢動作、八格姿勢檢查與重設，不寫入存檔或學習紀錄。正式版共用這兩套 V2 素材，但沿用正式戰鬥的傷害時序與屬性特效，不使用示範頁的簡化回合或火焰演出；目前為八格關鍵姿勢，尚非完整逐格或骨骼動畫。
- 素材、製作提示詞與限制見 `docs/visual-pilot.md`。

## 單人學習循環

- 一般不限時單人冒險，會在每次作答後儲存學習進度；新冒險、續玩及重新載入都會保留。
- 依「運算 + 招式原始數字範圍」分別調整難度。當前難度獨立答對四題才提升，答錯降低一級；使用提示不會推高難度。
- 第一個提示免費且只提供思考方向，後續解題步驟維持原本 XP 費用。使用提示仍保留正常戰鬥獎勵。
- 答錯或使用提示的技能，在至少回答另外兩題後，選到相符招式時優先出新題複習；只有不看提示答對新題，才清除該次待複習紀錄。
- 家長儀表板顯示獨立答對、提示後答對、完成複習及待複習技能數；可獨立重設學習進度，不會刪除歷史遊戲紀錄。
- 紀錄以裝置共用，非個別兒童帳號，儲存於 `mathMonsterBattle_learning_v1`。不回推舊紀錄，清除瀏覽器資料會遺失。儲存失敗時本次遊戲仍可繼續，但不能保證重新載入後保留。
- Co-op、PvP、計時、每日挑戰與連勝塔維持原有難度規則，不寫入此學習進度。

## 戰鬥命中演出

- `effectTiming.ts` 定義招式命中延遲與命中回饋強度。戰鬥流程在扣血／格擋／閃避結算時寫入 `atkEffect.impact`，畫面不再從招式開始時間猜測命中。
- `useAttackImpactPhase.ts` 只控制命中後的停頓、震動與收尾，支援重複施放同一招，並於清除招式、低效能模式或卸載時取消計時器。
- 答對提示音與真正命中音分開；PvP 等飛行、受擊與特效清除後再交棒，致命攻擊也先保留短暫受擊演出。
- 局部命中光效取代全戰場明暗濾鏡；普通攻擊不縮放鏡頭，重擊／暴擊使用較強但有上限的回饋。保留原本八屬性特效與角色比例。
- 本階段不增加新戰鬥規則或角色姿勢素材；既有屬性特效內部的逐粒子飛行軌跡仍沿用原動畫。

## 戰場站位與遮擋

- 戰場固定保留畫面高度的 55%，不隨選招、題目或攻擊文字改變；空間不足時只捲動操作區，切換階段會回到操作區頂部。
- 依實際血條尺寸及素材透明留白計算安全站位，避開 HUD 與其他單位；空間不足才等比例縮小，不裁切角色、不更換低解析素材。
- 同一場遭遇保留已量測的最大 HUD 高度，避免狀態標籤消失後角色突然放大；螢幕尺寸改變時重新量測。
- 站位錨點與攻擊／受擊動畫分開，前衝與閃避依可用空間限制位移；特效目標跟隨穩定錨點。蓄力與連擊提示移至操作區，不再蓋住後排角色。
- 站位只在版面或單位資料改變時計算，不新增逐幀 DOM 量測。

## 敵方提示與操作時機

- Boss 蓄力、轉階段、封印及毒傷等提示，點擊快轉與自動等待共用一次性的後續動作；舊計時器不能再次執行，也不能清除後來的提示。
- 快轉提示不等於跳過敵方攻擊。毒傷致命時先完成倒下／隊友接替流程，不提前開放選招。
- 戰鬥重設會清除待執行動作；暫停中不自動續接提示，恢復後可點擊繼續。攻擊演出中的文字不顯示可繼續箭頭。
- Boss 攻擊倍率與背水一戰倍率直接取自平衡設定。

## Boss 預告與打斷戰術

- 選招畫面以相同的 Boss 決策函式預估下一步（攻擊、蓄力、釋放或封印）。預告依目前血量與回合計算，玩家命中後的轉階段、冰凍或擊倒可能改變結果。
- Boss 已蓄力時，可先選「穩健打斷」（預設）或「強攻打斷」，再搭配任一未鎖定招式，題目難度不變。
- 穩健打斷：直接傷害乘以 0.75，免除蓄力反擊。強攻打斷：保留原本直接傷害及 20% 蓄力反擊。倍率集中於 `balanceConfig.ts`；整數傷害仍依原流程取整與減傷。
- 答對命中皆能打斷蓄力，但不會跳過後續敵方回合；答錯不會保護玩家。護盾全擋仍可打斷，沿用原規則。
- 戰術存於該題目的 metadata，命中時再次確認 Boss 正在蓄力才套用；一般敵人、未蓄力 Boss、PvP 與既有被動不調整。舊題目未指定戰術時保留原反擊規則。
- 新增介面僅使用靜態 CSS 與選招時的計算，不增加粒子、逐幀更新或全畫面濾鏡。
- 桌面預告與招式並排；小螢幕操作區在空間不足時可捲動，不縮小按鈕或壓縮角色比例。

## 目前架構（2026-02）

- `src/App.tsx`
  - 僅負責跨畫面 shell：路由 handoff、設定畫面進出、音樂切換與 preload。
  - `BattleScreen` 使用 lazy loading。
- `src/hooks/useBattle.ts`
  - 對外 typed public API（`state / actions / view`）。
- `src/hooks/useBattleCore.ts`
  - 戰鬥主協調器（已拆出大量 battle 子模組）。
- `src/hooks/battle/*`
  - reducer / flow / resolver / orchestrator 分層。
  - 目前新增 `useBattleOrchestrationState.ts`、`useBattleFlowState.ts` 收斂 orchestration state。
